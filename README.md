# 🥀 Emo Monkey Typist 🖤

Emo Monkey Typist is a moody, themed typing test application designed for those who want to practice their typing speed and accuracy with a dark, "emo" aesthetic. 

## ⌨️ Features

* **Real-time Statistics**: Track your WPM (Words Per Minute), accuracy, and elapsed time as you type.
* **Moody Aesthetic**: A customized dark interface featuring a specialized cursor and themed color palette.
* **Minimalist Design**: Focus entirely on the text without unnecessary distractions.
* **Responsive Interface**: Designed to provide a smooth typing experience within your web browser.

## 🚀 How to Use

Simply open `emomonkeytypist.html` in any modern web browser to begin your typing session. Press `Tab` to restart the session at any time.
